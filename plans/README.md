# Endsem plan, Monsoon 2026 (20 to 28 Nov)

Two files to load into the planner with the **import** button:

- `endsem-exams.json`: the five endsems (dna, osn, aad, prob, science) with a topic checklist each.
  It replaces only your exams, everything else stays.
- `endsem-study-plan.ics`: 32 study blocks from 20 to 28 Nov, merged into the calendar as events.
  Importing it twice doesn't add duplicates.

Sync carries both to the phone.
